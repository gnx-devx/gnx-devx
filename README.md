### 🚀 Proyecto Destacado

**[Clash Royale Data Analysis](https://github.com/gnx-devx/clash-royale-data-analysis)**
Sistema de predicción de resultados de partidas mediante Machine Learning, con un dataset propio de más de 310.000 partidas reales obtenidas vía API oficial.
- Pipeline completo de extracción, transformación y limpieza de datos
- Entrenamiento y comparativa de 6 modelos de clasificación (Random Forest, XGBoost, Gradient Boosting, KNN, Regresión Logística, Árbol de Decisión)
- Mejor resultado: Random Forest con 59,5% de exactitud y ROC-AUC de 0.636
- Aplicación de validación cruzada, RFECV y técnicas de explicabilidad de modelos
- Metodología Scrum · Trabajo de Fin de Grado defendido ante tribunal académico (UCLM)
